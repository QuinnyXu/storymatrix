# 故事数据库模板 · 字段说明 (v1.0)

故事数据库标准模板。每张表第一列是 ID；其他表用 ID 引用它（像关系数据库）。表名、列名按名称匹配，可以插入新列，列的顺序随意。列名带「（自动）」的是公式列，仪表盘不读。

日期写法: 日期可写：2031-07-11 · 2031-07 · 2031 · 2031 春 / 夏 / 秋 / 冬 · 2031 春节（查「节日」表）· 约 1850 · 也可以是 Excel 日期。

状态取值: 定 = 已定 · 暂 = 暂定 · 议 = 提议 · 缺 = 待填 · 推 = 推算 · 弃 = 作废

## 设置 / Settings（可选）

整本书的设置：每行一个「项目 / 值」。不填就用默认值。

| 列名 | 英文列名 | 类型 | 必填 | 说明 | 也认作 |
|---|---|---|---|---|---|
| 项目 | Key | text | ✓ |  | 设置项 |
| 值 | Value | text |  |  |  |
| 说明 | Note | text |  |  | 备注 |

| 项目 | 默认 | 说明 |
|---|---|---|
| 书名 (Title) |  | 仪表盘标题 |
| 英文书名 (English title) |  | 英文界面用 |
| 主要人物 (Main characters) |  | 人物ID，用顿号分隔；不填则用「人物.主要人物」列，再不填按出场次数取前 8 位 |
| 显示起始 (Display from) |  | 时间轴默认起点，如 2030 |
| 显示结束 (Display to) |  | 时间轴默认终点 |
| 参照日期 (Reference date) |  | 人物档案里「当前年龄」按这一天算 |
| 已定状态 (Decided status) | 定 | 这个状态的行若还含「未定标记」会被提醒 |
| 作废状态 (Dropped status) | 弃 | 这个状态的行在图上隐藏（引用仍有效） |
| 未定标记 (Open markers) | 【缺】、【议】、【暂】、待定 | 文字里出现这些词说明还没定 |
| 状态取值 (Status values) | 定、暂、议、缺、推、弃 | 状态列可用的值（按顺序配色） |
